# Precision Analytical Design System — Stitch Project 2102480190062873158

## Brand & Style
This design system is engineered for a high-tier Data Analyst portfolio, blending the rigor of scientific inquiry with the elegance of premium editorial design. The brand personality is **authoritative, meticulous, and visionary**.

The aesthetic follows a **Modern Professional** style with significant **Glassmorphic** and **Technical** influences. It utilizes high-contrast typography and subtle textural details, such as microscopic data grids and light-leak refractions, to simulate a high-end digital laboratory environment.

## Color System
- **Primary:** `#0A192F` — A midnight navy used for core backgrounds and deep structural layers.
- **Secondary (Cyan):** `#00F0FF` / `#D3FBFF` — Electric Cyan used for critical data points, call-to-actions, and active states.
- **Tertiary (Mint/Teal):** `#64FFDA` / `#38DEBB` — Soft technical green for success states, secondary metrics, and decorative accents.
- **Neutrals:** Cool slates and silvers (`#8892B0`, `#CCD6F6`, `#D9E2FF`).
- **Base Background:** `#07122A`

## Typography
- **Headlines / Nameplate:** `Literata` (Refined serif providing an editorial and authoritative "expert" voice).
- **Body & Interface:** `Hanken Grotesk` (Sharp and modern sans-serif for high-density information).
- **Technical & Data Labels:** `JetBrains Mono` (Metadata, code snippets, KPI counters, and skill badges).

## Layout & Elevation
- **Surface:** Semi-transparent containers (`rgba(16, 27, 51, 0.6)`) with `20px` backdrop blur.
- **Accent Edges:** Cards with 1px border gradient from `rgba(255, 255, 255, 0.08)` to `rgba(0, 240, 255, 0.3)`.
- **Glow Elements:** Soft outer glow (Cyan, 10% opacity, 100px blur).
